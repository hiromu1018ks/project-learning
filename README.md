# project-learning

superpowersで開発したプロジェクトを、初学者向けの学習教材に変換するClaude Codeスキルです。

実装コードを読み、「利用者の操作ごとに章を切った解説書(walkthrough形式)」を`docs/learning/`に生成します。各章では、その操作で動くコードを実行の順番どおりに追うため、「この操作の裏で何が起き、なぜそうなっているのか」を読みながらたどれます。AIに開発を任せても、動いたコードの中身をあなた自身が理解できる状態を作ります。

## インストール

```bash
npx skills add hiromu1018ks/project-learning
```

このコマンドは、GitHubからこのスキルをダウンロードして、お使いのClaude Codeで使える状態にします(npmの実行にはNode.jsが必要です)。

## 使い方

superpowersによる設計 → 計画 → 実装が完了したプロジェクトで、次のように言います。

```
このプロジェクトを学習教材にして
```

続きを書いてほしいときは、次のように言います。

```
前回に続き学習したい
```

スキルが自動で起動し、流れは次のとおりです。

1. `LEARNING_STATE.md`(進捗記録)の確認
2. 実装コードを読み、利用者が行える操作の列挙
3. 章リスト(章0+操作ごとの章)の提案と確認
4. 1章分の解説書をMarkdownで執筆(1回の実行につき1章)
5. 同梱スクリプトによるHTMLと目次ページ(index.html)の生成
6. 進捗記録と「再開地点」の更新

初回に章リストを固め、以降は「続きを学習したい」と言うたびに1章ずつ書き足します。章どうしは前章の続きから始まるため、複数回に分けても解説書全体がつながります。

## 出力物

```
LEARNING_STATE.md      学習の進捗記録(章リスト・執筆日・再開地点)
docs/learning/
├── 00-junbi.md        章0: この解説書の読み方(初回のみ)
├── 01-xxxx.md         章1以降: 操作ごとの章(元原稿。手で編集するのはこちら)
├── NN-xxxx.html       変換スクリプトが生成(毎回全再生成される)
└── index.html         目次ページ(自動生成、ブラウザで開くと読める)
```

## 必要なもの

- [Claude Code](https://claude.com/claude-code)(superpowersプラグイン推奨)
- Node.js 18以上(HTML変換スクリプトの実行に使用)

## 教材の方針

- 読者は、プログラミング経験がほぼゼロの初学者を想定する
- 章の単位は「利用者が行う操作1つ」。各章は①操作手順→②流れの全体図→③実行の追跡→④登場ファイル一覧の4パートで構成する
- 章どうしは前章の続きから始まる。別の日に続きを書いても、解説書全体がつながる
- コードは実ファイルからそのままコピーし、10行以内の断片に分け、直後に「行ごとのやっていること」の表を添える
- 専門用語は、初出時に必ず平易な定義を併記する
- 例え話は使わず、テキスト図と表で構造を視覚的に示す

## 構成

```
project-learning/          ← スキル本体(npx skills add でインストールされる部分)
├── SKILL.md               ← スキルの手順書
├── scripts/build-html.mjs ← md → html 変換スクリプト
└── assets/
    ├── marked.esm.js      ← Markdown 変換エンジン(marked v18, MIT)
    ├── marked-LICENSE.txt
    └── style.css          ← 教材ページのデザイン
```
